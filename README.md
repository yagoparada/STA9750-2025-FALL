# STA9750 – Fall 2025 Projects

This repository contains the projects completed for STA9750 (Baruch College), covering the full data analysis workflow: data acquisition, cleaning, exploratory analysis, visualization, and statistical inference in R.

## 📁 Projects

- **[MP01 – Netflix Top 10 Analysis](https://yagoparada.github.io/STA9750-2025-FALL/mp01.html)**: Explored global and country-level Netflix viewership data to answer key questions on content trends and prepared press-release style summaries.
- **[MP02 – Housing Affordability (YIMBY Analysis)](https://yagoparada.github.io/STA9750-2025-FALL/mp02.html)**: Investigated the relationship between zoning permissiveness, housing supply, and rent burden across U.S. metro areas using Census and BLS data.
- **[MP03 – NYC Urban Forest Analysis](https://yagoparada.github.io/STA9750-2025-FALL/mp03.html)**: Mapped and analyzed NYC's street tree data by council district, identifying maintenance priorities and proposing a district-level intervention.
- **[MP05 – BLS Employment Data: Initial Estimates vs. Final Numbers](https://yagoparada.github.io/STA9750-2025-FALL/mp05.html)**: Investigated the accuracy of BLS Current Employment Statistics (CES) revisions over time using hypothesis testing.
- **[Course Project – NYC Subway Crime Analysis](https://yagoparada.github.io/STA9750-2025-FALL/courseproject_sq1)**: Analyzed crime distribution across the NYC subway system using MTA data.

## 🛠️ Tools & Technologies

- **Language**: R
- **Data wrangling**: tidyverse, dplyr, tidyr, stringr, lubridate
- **Data acquisition**: httr2, rvest (web scraping/APIs), tidycensus
- **Visualization**: ggplot2, plotly, leaflet, DT
- **Spatial analysis**: sf
- **Statistical inference**: infer (t-tests, proportion tests)
- **Reporting**: Quarto (.qmd), published via GitHub Pages

## ✨ Features

- Reproducible R Markdown/Quarto reports combining code, narrative, and visualizations
- Interactive maps and charts (leaflet, plotly, DT)
- Statistical hypothesis testing applied to real-world policy questions
- End-to-end workflow: raw data acquisition → cleaning → analysis → policy recommendations
